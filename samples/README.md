# 가상 시험 자료 (samples)

PLAN.md 작업 1에서 만든 시험 자료다. 앱이 제대로 동작하는지, 성공 기준(SC-1~SC-3)을 얼마나 지키는지 확인할 때 쓴다.

> ⚠ 모든 자료는 실습용으로 지어낸 **가상 데이터**다. 테이블 이름(`VT_` 로 시작)과 기관 이름(`가상기관 01` 등)은 실제 온비드와 관계없고, 개인정보는 들어 있지 않다.

## 들어 있는 것

| 위치 | 내용 | 쓰는 곳 |
|---|---|---|
| `requirements/req-01~05.txt` | 가상 자료 요구문 5건 (기간·대상·기준일 함정이 하나씩 들어 있음) | 가이드 입력칸 ① |
| `table-definition.txt` | 가상 테이블 4개의 정의서 (코드표·관계 포함) | 가이드 입력칸 ② |
| `answers/answer-01~05.sql` | 요구문별 정답 쿼리 (Oracle) | SC-2 측정 |
| `excel/excel-01~05.xlsx` | 합계·소계를 일부러 틀리게 만든 결과 엑셀 | 엑셀 점검, SC-3 측정 |
| `answer-key.md` | 요구문별 정답 조건, 엑셀별 정답 오류 위치 | SC-1·SC-3 채점 |
| `mock-guide.json` | KOBI 없이 개발할 때 쓰는 가이드 예시 응답 | 작업 5 |
| `mock-excel.json` | KOBI 없이 개발할 때 쓰는 엑셀 대조 예시 응답 | 작업 12 |
| `make-excel.mjs` | 엑셀 5개를 다시 만드는 스크립트 (새 패키지 필요 없음). 화면의 [예시 엑셀로 점검]이 쓰도록 `public/samples/`에도 같은 파일을 만든다 | — |

## 엑셀 다시 만들기

```bash
node samples/make-excel.mjs
```
